## 等价类划分

**结论**：把预计采用相同处理方式的输入划为一类，选代表值验证。有效输入与无效输入都应考虑。

**例子**：年龄只接受 18 到 60 的整数，可先划分为小于 18、18 到 60、大于 60，并补充空值、小数和非数字输入。

**易错点**：数字范围之外的格式错误，不能只用一个超范围数字代替。不同无效原因可能触发不同处理路径。

## 边界值分析

对于闭区间 `[18, 60]`，可选取边界及其邻近值：

| 输入 | 预期 |
| --- | --- |
| 17 | 拒绝：低于下界 |
| 18、19 | 接受 |
| 59、60 | 接受 |
| 61 | 拒绝：高于上界 |

**易错点**：边界包含与否必须从需求确认；日期、字符串长度和数组索引也存在边界。具体测试集合取决于采用的边界覆盖准则。

## 判定表与状态迁移

**结论**：多个条件组合决定动作时可用判定表；结果依赖历史状态时可用状态迁移。

**例子**：是否会员、是否达到金额门槛共同决定折扣，适合判定表；订单从待支付到已支付再到已取消，适合状态迁移。

**易错点**：不能只测合法迁移。已取消订单再次支付、重复取消等非法或重复请求也需要明确预期。
