## 绝对路径与相对路径

**结论**：绝对路径从 `/` 开始，相对路径从当前工作目录出发。`.` 表示当前目录，`..` 表示父目录。

```bash
pwd
ls -lah
find . -maxdepth 2 -type f -name '*.md'
```

**易错点**：文件名含空格时应引用路径；Shell 会先处理未引用的通配符。上例给 `*.md` 加引号，是把匹配任务交给 `find`。

## 管道不自动传递标准错误

**结论**：`|` 默认把前一个命令的标准输出连接到后一个命令的标准输入。标准错误是另一条流。

**易错点**：`command > file 2>&1` 与 `command 2>&1 > file` 不等价，重定向按从左到右的顺序处理。前者把两种输出都送到文件。

## 文本过滤

```bash
printf 'INFO started\nERROR timeout\n' | grep 'ERROR'
```

**预期结果**：输出 `ERROR timeout`。`grep` 适合按内容过滤，`find` 适合按路径、类型等文件属性查找。

::: warning 覆盖风险
`>` 会创建或截断目标文件，`>>` 是追加。练习重定向时使用独立练习文件，不要把真实笔记作为输出目标。
:::
