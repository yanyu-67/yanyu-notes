## rwx 与数字权限

**结论**：读、写、执行分别对应 4、2、1，按所有者、所属组、其他用户排列。例如 `640` 表示所有者读写、组用户只读、其他用户无权限。

```bash
id
ls -ld .
umask
```

**易错点**：`chmod 777` 不是通用的报错修复方式，会扩大不必要的访问权限。应先判断操作对象、执行用户和需要的最小权限。

## 目录上的执行权限

**结论**：目录的 `r` 允许列出目录项名称，`x` 允许搜索或穿过目录，`w` 与目录项的增加、删除有关。

**易错点**：能否删除一个文件通常主要取决于父目录的写入和执行权限，而不是文件自身是否可写；粘滞位、ACL 等机制还可能增加限制。

## umask 是权限掩码

**结论**：创建文件时，程序申请的权限会被 umask 屏蔽部分位。常见普通文件申请 `666`、目录申请 `777`，但具体程序可能请求更严格的权限。

**易错点**：普通文件不会因为 umask 很宽松就自动拥有执行权限。umask 是按位屏蔽，不应在所有情况下都当作十进制减法。
